## Descrição

Projeto desenvolvido para a Prova do Primeiro Bimestre da disciplina de DevOps.

O projeto consiste na construção de uma API de Reservas utilizando Node.js, Express e PostgreSQL, posteriormente containerizada com Docker e Docker Compose e provisionada na AWS utilizando Terraform.

## Tecnologias

- Node.js
- Express
- PostgreSQL
- Docker
- Docker Compose
- Terraform
- AWS
- Git
- GitHub

## Objetivo

Construir uma infraestrutura reproduzível para execução da API de Reservas, aplicando conceitos de versionamento, containers, infraestrutura como código, redes, banco de dados e gerenciamento de estado.
